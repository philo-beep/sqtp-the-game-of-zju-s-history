# 内容管理后台工作说明

- **文件路径**：`技术组/02-admin-web/02-admin-web-WORKSPACE.md`
- **用途**：说明剧本配置与管理后台的开发范围。
- **谁该读**：成员2、内容组接口人、游戏引擎成员、平台后端成员。
- **何时更新**：剧本字段、权限或发布流程变化时。

## 一句话定位

负责把内容组提供的校史剧本配置成系统可以读取和运行的数据。

## 具体职责

- 管理员登录和权限页面。
- 剧本创建、编辑、保存、发布和下线。
- 角色、章节、公共剧情和私密线索配置。
- 任务、答案、投票选项和结局条件配置。
- 表单校验、版本状态和配置预览。
- 房间及游戏记录的基础查看页面。

## 输入与产出

**输入：**内容组提供的剧本、角色、线索、任务、答案和结局规则；平台后端提供的鉴权和数据接口；游戏引擎约定的数据字段。

**产出：**管理后台页面、表单校验、剧本配置数据和发布状态操作。

**下游：**游戏引擎读取已发布配置；玩家端展示配置对应的游戏内容。

## 协作关系

- 与内容组确认字段含义、必填项和版本状态。
- 与 `03-game-engine` 确认结局条件、推进条件和线索发放格式。
- 依赖 `04-platform-server` 提供管理员鉴权、剧本 CRUD 和文件接口。

## 明确边界

- 不直接执行游戏状态转换。
- 不在后台前端计算最终结局。
- 不修改玩家端页面和数据库底层实现。

## 完成标准

内容组可以不改代码地录入、校验、发布和下线一套剧本；已发布剧本可以被游戏引擎读取并成功开局。

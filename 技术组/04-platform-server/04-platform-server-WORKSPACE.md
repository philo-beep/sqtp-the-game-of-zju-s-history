# 平台后端与云服务工作说明

- **文件路径**：`技术组/04-platform-server/04-platform-server-WORKSPACE.md`
- **用途**：说明基础后端、数据库、实时通信和云环境的开发范围。
- **谁该读**：成员4、游戏引擎成员、玩家端成员、管理后台成员。
- **何时更新**：接口、数据库、部署或运行环境变化时。

## 一句话定位

负责用户身份、数据存储、接口通信和云端运行环境，为其他模块提供稳定基础。

## 具体职责

- 微信登录、用户身份和管理员权限。
- 用户、房间、剧本、游戏记录的基础数据接口。
- 数据库表结构、迁移和基础访问层。
- WebSocket 连接、房间广播和断线重连基础能力。
- 图片、音频等资源上传和对象存储。
- 缓存、日志、错误记录和数据备份。
- 开发、测试、生产环境部署与基础监控。

## 输入与产出

**输入：**游戏引擎的状态和数据需求；管理后台的配置字段；玩家端的登录、查询和提交请求。

**产出：**稳定的 API、数据库、实时通信服务、部署配置、日志和备份方案。

**下游：**玩家端、管理后台和游戏引擎共同调用这些基础能力。

## 协作关系

- 与 `03-game-engine` 共同设计房间、游戏状态和事件存储。
- 与 `01-player-miniapp` 约定登录、查询、提交和实时消息接口。
- 与 `02-admin-web` 约定剧本 CRUD、发布和权限接口。

## 明确边界

- 不负责章节推进和结局计算等游戏规则。
- 不负责玩家端和管理后台页面。
- 不把密钥、密码和生产数据提交到 Git 仓库。

## 完成标准

新环境可以按照文档启动服务；用户能够登录并读写必要数据；多人房间状态可以实时同步；服务有日志、备份和基本故障定位能力。

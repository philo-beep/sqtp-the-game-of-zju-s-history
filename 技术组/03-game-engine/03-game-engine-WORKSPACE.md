# 自动游戏引擎工作说明

- **文件路径**：`技术组/03-game-engine/03-game-engine-WORKSPACE.md`
- **用途**：说明自动主持和游戏规则后端的开发范围。
- **谁该读**：成员3、玩家端成员、平台后端成员、内容组接口人。
- **何时更新**：房间状态、章节推进或结局规则变化时。

## 一句话定位

负责让系统自动完成开局、推进剧情、发放线索、处理答题投票和结算。

## 具体职责

- 房间状态机和开局条件判断。
- 玩家加入、准备、角色分配和游戏开始。
- 章节推进、任务完成和线索发放。
- 答题校验、投票开启、截止和结果计算。
- 结局条件匹配、分数计算和结果保存。
- 倒计时、超时、重复提交和非法操作处理。
- 玩家掉线后的状态恢复逻辑。

## 输入与产出

**输入：**管理后台发布的剧本配置、平台后端提供的用户和房间基础服务、玩家端提交的游戏操作。

**产出：**游戏状态机、游戏操作接口、状态事件、结算结果和规则文档。

**下游：**玩家端展示状态和结果；管理后台查看游戏记录；平台后端负责保存和推送。

## 协作关系

- 与 `04-platform-server` 共同定义房间表、游戏记录表和实时事件格式。
- 与 `02-admin-web` 共同定义章节、线索、任务和结局字段。
- 与 `01-player-miniapp` 共同联调完整玩家流程。

## 明确边界

- 不负责微信登录和云服务器运维。
- 不负责后台页面和小程序视觉交互。
- 不把关键规则只放在前端执行。

## 完成标准

一套已发布剧本可以在无人主持的情况下完成从建房、开局、剧情推进、线索发放、答题投票到自动结算的完整流程。
